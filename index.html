◈Опубликован

Веб-интерфейс

Сайт опубликован и открывается по защищённому HTTPS-адресу.

⌘Настроено

Запуск в Telegram

Кнопка Mini App настроена через BotFather. Серверная проверка пользователя требует настройки.

◎Локально

Профиль пользователя

В браузере доступен локальный профиль. В Telegram профиль будет привязан к вашему Telegram ID после настройки серверного хранилища.

⌁Требует настройки

Сервер и база данных

API для Telegram, профилей и персональной памяти подготовлен. Для запуска нужны база Supabase и серверные настройки Vercel.

Добро пожаловать

Одно пространство для работы с AI.

ORVEX Agent создаётся как персональное рабочее пространство, в котором будут собраны ИИ-помощник, инструменты и автоматизация. Сейчас мы знакомим вас с уже работающими функциями и тем, что находится в разработке.

Ваше пространствоПрофиль и персональные настройки, привязанные к вашему Telegram-аккаунту.
Развитие по этапамНовые функции будут появляться постепенно, а их статус будет указан прямо в приложении.
Персональные функции

Настройки и память под вашим контролем.

В ORVEX Agent уже подготовлены функции персонального пространства:

ПрофильРедактирование личных сведений, интересов, языка, длины и формата ответов, а также собственных инструкций.
Персональная памятьДобавление, просмотр и удаление заметок, предпочтений, фактов и целей.
Ваши данныеМожно экспортировать данные или удалить профиль вместе с записями памяти. Настройки стиля ответов начнут влиять на ИИ после подключения чата.
Модели искусственного интеллекта

Вы сможете выбирать модель под задачу.

В планах подключить несколько ИИ-моделей с разными сильными сторонами: для повседневных вопросов, анализа, программирования и сложных задач.

Сравнение моделейБудут указаны особенности, ограничения и подходящие сценарии каждой модели.
Честный статусНа данный момент реальные AI-запросы и выбор моделей в интерфейсе ещё не подключены. Список появится после интеграции и проверки.
Что дальше

Начните с персонального профиля.

После знакомства вы сможете создать профиль. По мере развития ORVEX Agent это описание будет обновляться вместе с доступными моделями, инструментами и возможностями.

Без фиктивных обещанийВ ознакомлении показываются только подтверждённые функции и явно обозначенные планы.

Ознакомление можно повторно открыть в любой момент из раздела «Мой профиль».
