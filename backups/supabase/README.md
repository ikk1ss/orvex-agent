# Supabase backup

Структурный снимок текущей схемы Supabase сохранён в `schema-inventory.md`.

**Важно:** репозиторий публичный. Поэтому сюда не добавлялись данные пользователей, переписки, Auth-пользователи, пароли, токены или ключи. Файл содержит только инвентаризацию структуры таблиц, применённых миграций и RLS-политик. Это не полный `pg_dump` и не резервная копия данных.

## Что сохранено

- Список применённых миграций на 2026-11-15.
- Список таблиц публичной схемы и их колонок.
- Список действующих RLS-политик.

## Что не сохранено

- Строки таблиц и пользовательские данные.
- Supabase Auth и Storage.
- Полный DDL всех функций, триггеров, индексов, ограничений и grants.
- Секреты, ключи, пароли и строки подключения.

Для полного восстановления базы нужен отдельный защищённый экспорт с данными. Его нельзя помещать в этот публичный GitHub-репозиторий.
