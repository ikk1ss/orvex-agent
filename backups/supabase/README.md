# Supabase backup

Статус: подготовлено место для резервной копии. Экспорт базы данных ещё не выполнен.

Перед применением миграций необходимо добавить проверенные файлы экспорта:

- `schema.sql` — структура базы данных и объекты схемы.
- `roles.sql` — определения ролей, если они присутствуют в экспорте.
- `data.sql` — данные, только после проверки на персональные и чувствительные сведения.

## Важные ограничения

- Не добавлять пароли, API-ключи, service_role keys, JWT secrets или строки подключения с паролями.
- Не загружать персональные данные пользователей в публичный репозиторий.
- Если экспорт содержит персональные данные, хранить его отдельно в приватном зашифрованном хранилище, а не в GitHub.
- Наличие этой папки само по себе не означает, что резервная копия уже создана.

## Цель

Сохранить состояние Supabase проекта Orvex до применения новых миграций для гостевой квоты и внешней авторизации.

Дата подготовки: 2026-11-15.
